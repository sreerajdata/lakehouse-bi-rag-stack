## System Requirements
- Python 3.6 or higher
- Node.js 12 or higher
- Docker

## Installation
1. Clone the repository:
   ```
   git clone https://github.com/Sreerajph01/E2E-lakehouse-stack.git
   cd E2E-lakehouse-stack
   ```
2. Install the requirements:
   ```
   pip install -r requirements.txt
   npm install
   ```

## Quick Start
- Start the services:
   ```
   docker-compose up
   ```
- Access the application at [http://localhost:8080](http://localhost:8080)

## Service Access
- API is accessible at [http://localhost:8080/api](http://localhost:8080/api)
